# 协作平台快速入门指南

## 1. 新用户首次进入协作平台，如何快速完成第一个项目协作？

如果你刚刚登录协作平台，希望在最短时间内熟悉界面并跑通“进入空间 → 创建或打开项目 → 编写与批注文档 → 添加或邀请同事协作”的完整流程，请按以下五步操作：

1. **第一步：确认并切换工作空间**：在页面左上角 **「工作空间切换器」** 核对当前所在的企业工作空间（`workspace`）及你的成员角色标签（`admin`、`member` 或 `guest`）。
2. **第二步：浏览或创建第一个项目**：在左侧导航栏点击 **「项目中心」**，浏览已有公开项目（`workspace_public`）；若你的角色为 `admin` 或 `member`，可点击右上角 **「+ 新建项目」** 创建你的第一个团队项目。
3. **第三步：在项目内创建文档并协同批注**：进入项目详情页，切换到 **「项目文档」** 页签，点击 **「+ 新建文档」** 编写项目计划，并通过划词 **「添加批注」** 或底部 **「讨论区」** 与同事互动。
4. **第四步：添加项目协作者或分享项目**：在项目详情页点击 **「项目成员与权限 > + 添加协作者」** 为同事分配权限，或点击右上角 **「分享项目」** 将项目链接发送给团队成员。
5. **第五步：对照上手清单自查或向 Ordo 咨询下一步建议**：对照上述四个环节在页面核对空间、项目、文档与协作者配置是否就绪；若在某一步遇到操作疑问，可点击右上角 **「帮助与支持 > Ordo 智能支持中心」** 说明你当前已完成的步骤，获取下一步页面操作指导。

## 2. 如何进入和切换工作空间？

- **适用角色**：全体角色（`admin`、`member`、`guest`）。
- **前提条件**：已使用企业分配的账号通过登录页（`/auth/login`）成功登录协作平台。
- **页面路径与入口**：顶部导航栏左上角 **「工作空间切换器」**，以及右上角 **「个人头像 > 账号与身份」**。
- **操作步骤**：
  1. 登录协作平台后，查看左上角 **「工作空间切换器」** 显示的当前企业名称与工作空间名称。
  2. 点击 **「工作空间切换器」** 下拉菜单，查看你已加入的工作空间列表及每个空间右侧显示的角色徽标（`管理员 admin`、`正式成员 member` 或 `访客 guest`）。
  3. 点击目标工作空间名称即可切换至该工作空间；如需核对详细的 `user_id`、`tenant_id` 与 `workspace_id`，点击右上角 **「个人头像 > 账号与身份」** 查看。
- **预期结果**：页面主视图自动刷新为所选工作空间下的 **「工作台」** 与 **「项目中心」** 数据，不同企业租户（`tenant`）的数据彼此严格隔离。
- **失败时的处理方法**：
  - **下拉列表中找不到目标工作空间**：说明你的账号尚未被邀请加入该工作空间，或邀请尚未接受。请联系该工作空间的管理员（`admin`）在 **「空间管理 > 成员与邀请」** 中核对你的受邀账号与状态。
  - **切换后看不到任何公开项目**：请查看空间右侧的角色标签。若显示为 `guest`（访客），则默认不展示公开项目，仅展示已明确授权给你的项目。

## 3. 如何创建项目并选择公开或私有可见性？

- **适用角色**：仅工作空间管理员（`admin`）与正式成员（`member`）可创建项目；访客（`guest`）不支持创建项目。
- **前提条件**：已进入目标工作空间，且当前账号角色为 `admin` 或 `member`。
- **页面路径与按钮**：左侧导航栏 **「项目中心」** → 页面右上角 **「+ 新建项目」** 按钮。
- **操作步骤**：
  1. 在左侧主导航栏点击 **「项目中心」**，然后点击页面右上角的 **「+ 新建项目」** 按钮。
  2. 在弹出的 **「新建项目」** 配置面板中，依次填写以下基础信息：
     - **项目名称**（必填）：输入清晰的项目名称（如“2026 Q4 产品研发专项”，限 2～64 个字符）。
     - **项目标识（`project_id`）**：系统自动生成以 `proj_` 开头的小写字母、数字与下划线唯一标识（如 `proj_q4_dev01`），也可在创建时按统一格式规范自定义（固定前缀 `proj_`，后跟小写字母、数字或下划线，总长度 `8`～`32` 位，正则 `^proj_[a-z0-9_]{3,27}$`）。
     - **项目简介**（选填）：填写项目目标、里程碑说明或协作约定。
     - **可见性范围（必填）**：
       - 选择 **「团队公开（`workspace_public`）」**：本工作空间内的所有 `admin` 与 `member` 默认可见并可访问（`guest` 仍需单独授权）。
       - 选择 **「私有项目（`private`）」**：仅项目创建者、工作空间管理员（`admin`）及后续被明确添加进 **「项目成员与权限」** 列表的成员可访问。
  3. 确认配置无误后，点击右下角 **「创建并进入项目」** 按钮。
- **预期结果**：系统成功创建该项目并自动跳转至该项目的 **「项目概览」** 页面，创建者默认成为该项目的负责人（拥有 `manage` 权限）。
- **失败时的处理方法**：
  - **页面右上角「+ 新建项目」按钮置灰或不可见**：请检查右上角 **「个人头像 > 账号与身份」**，若当前角色为 `guest`，则无创建项目权限；如需作为内部成员开展工作，请联系本空间 `admin` 在 **「空间管理 > 成员与邀请」** 中调整你的角色。
  - **提示“项目标识已存在或格式不合法”**：请修改自定义标识，确保严格以 `proj_` 开头且仅包含小写字母、数字和下划线（总长度 8～32 位，符合 `^proj_[a-z0-9_]{3,27}$`）。

## 4. 如何查找、打开和管理已有项目？

- **适用角色**：`admin`（可查看并管理本空间全部公开与私有项目）、`member`（可查看全部公开项目及已授权私有项目）、`guest`（仅可查看已明确授权项目）。
- **前提条件**：已登录并进入目标工作空间。
- **页面路径与组件**：左侧导航栏 **「项目中心」**（含分类筛选页签）与顶部 **「全局搜索框」**。
- **操作步骤**：
  1. **按视图分类浏览**：点击左侧导航栏 **「项目中心」**，可在顶部切换 **「全部可见项目」**、**「我创建的项目」**、**「我参与的项目」** 或 **「已归档项目」** 页签，点击任意项目卡片即可打开该项目详情页。
  2. **按关键词或 ID 搜索**：在页面顶部 **「全局搜索框」** 输入项目名称关键词或准确的 `project_id`（如 `proj_q4_dev01`），在下拉结果中点击进入目标项目。
  3. **管理项目基础设置**（仅项目负责人与空间 `admin` 可操作）：进入项目详情页后，点击顶部最右侧的 **「项目设置」** 页签，可修改项目名称、更新项目简介、调整可见性范围（公开/私有）或将已完结项目设为归档。
- **预期结果**：快速打开目标项目并查看 **「项目概览」**、**「项目文档」** 与 **「讨论与批注」**。
- **失败时的处理方法**：
  - **搜索不到同事提到的项目**：若你是 `member` 且该项目为未授权的私有项目（`private`），或你是 `guest` 且尚未获得该项目授权，该项目不会出现在你的常规列表中。此时可点击 **「项目中心」** 右上角的 **「申请访问项目」** 按钮填写 `project_id` 直接发起 `read` 权限申请（如不清楚如何填写，可向 Ordo 智能支持中心咨询申请步骤，由你在页面完成提交）。

## 5. 如何在项目内创建文档、添加批注并与同事开始协作？

- **适用角色**：
  - 创建与编辑文档：`admin`，以及对该项目拥有 **「可编辑（`edit`）」** 或 **「可管理（`manage`）」** 权限的 `member`。
  - 添加批注与讨论：`admin`，以及对该项目拥有 `comment`、`edit` 或 `manage` 权限的 `member` / `guest`（仅拥有 `read` 权限的用户只能浏览，不能批注或编辑）。
- **前提条件**：已进入目标项目详情页，且具备上述对应项目权限等级。
- **页面路径与按钮**：**「项目详情页 > 项目文档」** 页签 → **「+ 新建文档」** 按钮。
- **操作步骤**：
  1. **创建与编辑文档**：在项目详情页点击 **「项目文档」** 页签，点击右上角 **「+ 新建文档」**，输入文档标题与正文内容（支持多级标题、表格、任务清单与代码块）。多人同时打开同一篇文档时，编辑器顶部会实时显示在线协作者头像并自动保存变更。
  2. **添加划词批注**：在文档正文中用鼠标选中需要讨论的文字段落，点击浮现工具栏中的 **「添加批注」** 图标，输入批注意见并可输入 `@姓名` 提及该项目内的协作者，点击 **「发布」**。
  3. **将同事加入项目协作**（项目负责人或 `admin` 操作）：点击项目详情页顶部的 **「项目成员与权限」** 页签，点击右上角 **「+ 添加协作者」**，从本工作空间成员列表中勾选目标同事，为其选择权限等级（`可编辑 edit`、`可批注 comment` 或 `只读查看 read`），点击 **「确定添加」**。
- **预期结果**：文档实时保存在项目内，被添加的同事可在自己的 **「项目中心 > 我参与的项目」** 中直接打开该项目与文档，并查看或参与批注。
- **失败时的处理方法**：
  - **打开文档后无法输入文字或找不到「添加批注」按钮**：请点击页面右上角查看当前权限标签。若显示为 **「只读（`read`）」**，说明你当前仅具备浏览权限（`read` 权限不自动包含批注或编辑能力），需联系项目负责人或空间 `admin` 在 **「项目成员与权限」** 中调整你的项目权限等级。

### 5.1 如何在文档批注或讨论中 @同事（@提及与批注通知）？

- **适用角色**：对该项目拥有 `comment`、`edit` 或 `manage` 权限的 `admin`、`member` 或 `guest`（仅拥有 `read` 只读权限的用户不支持发起批注或 `@` 提及）。
- **前提条件**：被 `@` 提及的同事必须已经是当前项目的有权访问者（如已添加进该项目 **「项目成员与权限」** 列表的协作者，或对公开项目默认有访问权的本空间成员）。
- **操作步骤**：
  1. 在项目文档中选中文本点击 **「添加批注」**，或点击文档底部的 **「讨论与批注」** 输入框。
  2. 在输入框中键入半角或全角 `@` 符号，系统会自动弹出当前项目可提及的协作者下拉列表；输入同事姓名关键词并点击选中目标同事（如 `@小林`）。
  3. 输入需要对方确认或回复的具体意见，点击 **「发布」** 按钮完成提交。
- **操作结果**：批注或讨论发布后，被提及的同事登录协作平台时，会在左侧导航栏 **「工作台 > 收到的批注提醒」** 列表中看到该条 `@` 提及记录，点击该条记录即可直接跳转并定位到对应文档段落。

## 6. 示例：新入职团队成员完成首次项目创建与协作闭环

> **示例说明（以下为假设情境，仅供演示上手流程，非当前用户真实状态）**：  
> **前提设定**：假设在“云帆数码”工作空间中，新入职运营专员小赵已被空间管理员（`admin`）设置为正式成员（`member`），首次登录协作平台筹备“秋季新品推广”项目。

1. **在页面核对身份与工作空间**：小赵登录后，在左上角 **「工作空间切换器」** 确认当前处于“云帆数码工作空间”且角色徽标为 `member`，并在右上角 **「个人头像 > 账号与身份」** 核对账号状态正常（如不清楚新用户建议操作顺序，可打开 **「Ordo 智能支持中心」** 咨询上手步骤指引）。
2. **创建项目与文档**：小赵点击左侧 **「项目中心 > + 新建项目」**，填写名称“秋季新品推广（`proj_autumn_01`）”，可见性设为 **「团队公开（`workspace_public`）」**。进入项目后，在 **「项目文档」** 页签点击 **「+ 新建文档」** 编写《推广排期表》。
3. **添加外部摄影顾问并分配批注权限**：外部摄影顾问胡老师在工作空间中的角色为访客（`guest`）。虽然 `proj_autumn_01` 是公开项目，但 `guest` 默认不可见公开项目，且小赵希望胡老师能在文档上留批注确认档期。于是小赵进入 **「项目成员与权限 > + 添加协作者」**，选中胡老师并分配 **「可批注（`comment`）」** 权限。胡老师登录后即可打开《推广排期表》，划词输入批注并点击 **「发布」**，顺利完成首次协作。

## 7. 常见问题（FAQ）

### 问：我刚登录协作平台，如何检查我还有哪些新用户上手步骤没完成？
答：你可以对照以下四项关键检查点在平台页面自查：（1）在左上角 **「工作空间切换器」** 确认已进入正确的企业工作空间并核对角色标签；（2）在左侧 **「项目中心」** 确认能正常打开公开项目或点击 **「+ 新建项目」**；（3）在项目 **「项目文档」** 页签确认可新建文档或选中文字点击 **「添加批注」** 并 **「发布」**；（4）在 **「项目成员与权限」** 确认已将所需协作同事加入项目。如果你在某一步不确定如何操作，可以打开右上角 **「帮助与支持 > Ordo 智能支持中心」**，向助手说明你当前做到哪一步，助手会为你提供下一步的页面操作指导（注：Ordo 不会自动读取你的后台配置状态）。

### 问：我在快速入门时想顺便测试一下平台开放的 API 接口，应该去哪里操作？
答：如果你需要对接或测试平台 API，请点击左侧导航栏底部的 **「开发者与 API 中心」**：先在 **「凭据管理」** 页面查看或创建绑定你账号的 API 凭据并勾选 `project:read` 权限范围，随后进入 **「沙箱调试台」** 页面即可自行选择测试凭据在线测试 `GET /sandbox/product/v1/me` 等固定接口。详细规范与参数说明请查阅《05 API 接入指南与接口说明》。
